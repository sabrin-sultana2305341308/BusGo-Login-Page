ABOUT BUSGO

A simple digital platform for bus travel.

BusGo is a project concept designed to make bus travel management easier for passengers. Users can create an account, securely sign in, and access the BusGo experience from one place.

How BusGo Works

First, a passenger creates a BusGo account. After registration, the passenger signs in using the same email or phone number and password. Successful login takes the user into the main BusGo system.

Account Instructions

Use accurate account information, choose a password you can remember, and keep your login details private. For this project demonstration, registration and login are the main features.
