# 🚌 BusGo — Login & Registration Page

A modern and responsive **login and registration page** for the BusGo online bus ticket booking website.

🌐 **Live Demo:** https://busgo-ticket-booking.netlify.app/

📂 **GitHub Repository:** https://github.com/sabrin-sultana2305341308/BusGo-Login-Page

---

## 📌 About the Project

**BusGo** is a bus ticket booking website project designed to provide users with a simple and user-friendly experience for booking bus tickets online.

This repository contains the **login and registration page** of the BusGo project.

The page includes:

* 🔐 User Login
* 📝 User Registration
* 👤 User Profile Information
* 🚪 Logout functionality
* ✅ Basic form validation
* 💾 Browser-based user data storage
* 📱 Responsive design
* 🎨 BusGo branding and custom logo
* 🚌 Bus/travel themed interface

---

## ✨ Features

### Login

Users can enter their email and password to log into the website.

### Registration

New users can create an account by providing:

* Full name
* Email address
* Password
* Phone number

### User Account

After logging in, the user's information can be displayed through the interface.

### Logout

Users can safely log out from the current browser session.

### Responsive Design

The page is designed to work on:

* 💻 Desktop
* 💻 Laptop
* 📱 Mobile
* 📱 Tablet

## 🚀 How to Run the Project

No installation or additional software is required.

### Option 1 — Open Locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The BusGo login page will open in your web browser.

### Option 2 — Use Live Server

If you use **Visual Studio Code**, you can install the **Live Server** extension.

Then:

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server**.

## 🔐 Authentication Note

This project currently uses **browser Local Storage** for demonstration purposes.

User information is stored locally in the browser using JavaScript.

Therefore, this implementation is intended for:

* Academic projects
* UI/UX demonstrations
* Frontend practice
* Prototype development

It is **not intended to be used as a production-grade authentication system**.

For a real-world application, authentication should be handled through a secure backend server and database.
